# Tarefa CSS - In Junior

Este repositório contém um projeto front-end desenvolvido como tarefa na IN Junior, com foco nos fundamentos e boas práticas de **CSS**. O projeto consiste em uma página pessoal individual estilizada, apresentando versões inicial e corrigida com melhorias de layout e estilo.

## Objetivo

Praticar conceitos essenciais de CSS, como:

- Seletores, classes e especificidade
- Tipografia com Google Fonts
- Estilização de listas, formulários e botões
- Organização de seções com `header`, `main`, `section` e `footer`
- Agrupamento visual de elementos com classes customizadas
- Responsividade básica com `meta viewport`

## Sobre o projeto

A **Página Individual** é uma página pessoal que apresenta:

- Foto e seção **"Sobre mim"** com biografia do desenvolvedor
- **Lista de Hobbies** organizada por grupos visuais
- **Top 5 Jogos** favoritos
- **Formulário de Feedback** para envio de mensagens
- **Rodapé** com ícones de redes sociais (Instagram, LinkedIn, Facebook, GitHub)

O repositório contém duas versões do projeto:
- `index.htm` + `index.css` — versão inicial da tarefa
- `corrigido.html` + `corrigido.css` — versão revisada com correções e melhorias de estilo

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/marcosgomes-dev/css.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd css/Projeto\ CSS/Tarefa\ de\ CSS
   ```
3. Abra o arquivo `corrigido.html` no navegador para ver a versão final.

Recomenda-se usar a extensão **Live Server** do VS Code para facilitar o desenvolvimento.
